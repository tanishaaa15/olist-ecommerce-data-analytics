# Part 2 — REST API

Build a FastAPI application.

Required endpoints

Products

GET /products

GET /products/{id}

Customers

GET /customers

GET /customers/{id}

Orders

GET /orders

GET /orders/{id}

GET /orders/{id}/details

Categories

GET /categories

GET /categories/translation

Pagination is required wherever applicable.
